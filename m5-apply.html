5.1 개인 실습: 내 업무 1건 적용

모듈 1의 업무 적용 지도에서 고른 칸으로 돌아갑니다. 아래 워크시트를 채우며 진행합니다. 실제 비공개 자료는 쓰지 않습니다. 자료가 필요하면 ① 공개 자료(ALIO·나라장터·data.go.kr), ② 가상 데이터, ③ 마스킹한 자료 중 하나를 씁니다.

실습 워크시트

① 업무 이름예: 월간 실적 보고서 초안 / 민원 답변 / 공고문 요건 검토 / 기관 비교
② 업무 유형 (A~E)A 문서작성 · B 규정해석 · C 민원응대 · D 데이터 · E 발표홍보
③ 선택 도구 + 이유ChatGPT / Claude / Gemini — 이 업무에 이 도구를 고른 이유 한 줄
④ 사용할 에이전트오늘 만든 GPT / Project / Gem 중 하나, 또는 새로 만들 것
⑤ 입력 자료와 보안 분류공개 / 가상 / 마스킹 — 마스킹했다면 무엇을 어떻게
⑥ 프롬프트 (5요소)역할 · 맥락 · 과제 · 형식 · 제약
⑦ 결과 검증 포인트무엇을 원문과 대조했는가, 틀린 곳은
⑧ 예상 절감 시간 / 다음 개선기존 ○분 → AI 활용 ○분, 다음에 지침에 추가할 것

공공데이터 옵션 (내 업무 자료를 쓰기 어려운 경우)

공공 예제 선택지
  • ChatGPT ALIO에서 우리 기관과 유사 기관 2곳의 "복리후생비" 공시 → 비교표 → 보고서 '주요 내용' 초안 (모듈 2 응용)
  • Claude 나라장터 공고 1건 + 「용역계약 일반조건」 → 적용 조항 대조표 → 검토 의견 1쪽 (모듈 3 응용)
  • Gemini data.go.kr "지자체 민원 통계" CSV → Sheets 집계 → 차트 → 민원 답변 Gem으로 상위 민원 유형 FAQ 초안 (모듈 4 응용)
강사 노트 · 순회 지도 포인트
  • 프롬프트에 형식이 빠진 교육생이 가장 많습니다. "결과물이 어떤 모양이면 좋겠어요?"라고 물어 주세요.
  • "안 돼요"의 80%는 ① 한도 초과 ② 파일 형식(HWP 미지원) ③ 너무 긴 요청. HWP는 PDF로 저장, 긴 요청은 둘로 나누게 합니다.
  • 잘 된 사례는 즉시 캡처해 두고 5.2 공유 때 먼저 발표시킵니다.

5.2 조별 공유

4~5명 조에서 1인 2분, 아래 3문장 형식으로 공유합니다. 조별로 "오늘 가장 써먹을 사례" 1개를 골라 전체에 1분 발표합니다.

1. "저는 [업무]에 [도구/에이전트]를 썼습니다." 2. "결과는 [잘된 점], 다만 [틀렸거나 아쉬운 점]이 있어서 [어떻게 검증/수정]했습니다." 3. "다음에는 지침에 [무엇]을 추가해서 [반복 활용 계획]입니다."
강사 피드백 체크
  • 검증 없이 "잘 됐다"로 끝난 발표 → "어디를 확인하셨어요?"로 되묻기
  • 보안 분류가 애매한 사례 → 5.3으로 자연스럽게 연결
  • 같은 업무에 다른 도구를 쓴 교육생이 있으면 비교 발언 유도

5.3 [투입 전 판단] 사내 정보 마스킹 등 보안 짚기

오늘 과정의 가장 중요한 10분입니다. 외부 생성형 AI는 기관 밖의 서버입니다. 입력하는 순간 외부 전송입니다. 아래 기준은 국가정보원 「공공분야 생성형 AI 활용 보안 가이드라인」과 일반 원칙을 바탕으로 한 것이며, 기관 자체 지침이 있으면 그것이 우선합니다.

마스킹·가명처리 실무 4단계

  1. 열(필드) 단위로 지우기엑셀·CSV는 이름·연락처 열을 통째로 삭제합니다. "숨기기"는 삭제가 아닙니다. 삭제 후 다른 이름으로 저장해 원본과 분리.
  2. 문서는 치환하기한글/워드 "찾아 바꾸기"로 기관명 → "A기관", 사람 이름 → "담당자1", 금액 → "○○억 원" 또는 자릿수만 유지("약 3천만 원대"). 치환표는 내 PC에만 보관.
  3. 구조만 보내기"이런 구조의 문서를 다듬어 줘"가 목적이면 내용 대신 목차와 각 항목 첫 문장만 보내도 충분한 경우가 많습니다.
  4. 결과 되돌릴 때 주의AI 결과를 받아 "A기관"을 다시 실제 기관명으로 바꾸는 작업은 AI 밖(내 PC)에서 합니다. AI에게 "A기관은 사실 ○○공단이야"라고 알려 주는 순간 마스킹이 무효가 됩니다.
□ 이 자료에 사람 이름·연락처·주소·식별번호가 있는가? □ 미공개 숫자(예산·인사·실적)가 있는가? □ 계약 상대방·외부 기관의 비공개 정보가 있는가? □ "내일 신문에 나와도 괜찮은가?" □ 기관 지침에 외부 AI 입력 기준이 있는가? 확인했는가? → 하나라도 "예/모름"이면 마스킹 또는 중단.

※ 요금은 2026년 10월 기준 대략치이며 변동됩니다. 기관 구매 시 학습 미사용·데이터 보관 위치·관리자 통제 조건을 계약서에서 확인하세요.

무료 한도를 아끼는 요령 6가지

  1. 도구를 나눠 쓴다. 초안은 ChatGPT, 긴 문서는 Claude, 시트·검토는 Gemini/NotebookLM. 한 도구에 몰면 한도가 빨리 옵니다.
  2. 긴 파일은 필요한 쪽만. 100쪽 PDF에서 10쪽만 필요하면 PDF를 잘라서 올립니다(한글·브라우저 인쇄로 페이지 범위 저장).
  3. 한 대화에 몰아넣지 않는다. 대화가 길수록 매 요청의 처리량이 늘어 한도가 빨리 소진됩니다. 주제가 바뀌면 새 대화.
  4. "다시 생성" 대신 "수정 지시". 전체 재생성은 비용이 큽니다. 바꿀 부분만 지시합니다.
  5. 에이전트에 지침을 넣어 둔다. 매번 긴 지침을 붙이는 대신 GPT/Project/Gem에 저장하면 입력량이 줍니다.
  6. 한도 메시지가 뜨면 다른 도구로. 오늘 배운 세 도구는 같은 일을 할 수 있습니다. 기다리지 말고 옮깁니다.
강사 노트 · 유료 전환 질문 받을 때

"어느 게 제일 좋아요?"에는 "어떤 업무가 제일 많으세요?"로 답합니다. 문서 작성 중심 → ChatGPT 또는 Claude, 규정·긴 문서 → Claude, Google 환경·데이터·발표 → Gemini. 개인 결제는 기관 지침과 비용 처리 가능 여부를 먼저 확인하도록 안내합니다.

공통 원칙 5가지

  1. 형식을 내가 정한다. (프롬프트 5요소 중 과제·형식은 필수)
  2. 없는 것은 "[확인 필요]"로 비우게 한다.
  3. 수치·조항·페이지는 반드시 원문 대조한다.
  4. 반복되는 일은 에이전트(GPT·Project·Gem)에 지침으로 넣는다.
  5. 입력 전에 "내일 신문에 나와도 되는가"를 묻는다.

과정 후 1주일 실천 체크리스트

  • 오늘 만든 에이전트(GPT/Project/Gem) 지침을 내 업무에 맞게 1회 수정
  • 실제 업무 1건을 공개/마스킹 자료로 AI와 함께 처리하고 걸린 시간 기록
  • 세 도구의 "학습 사용" 설정 재확인
  • 기관의 생성형 AI 활용 지침 유무 확인, 없으면 담당 부서에 문의
  • 팀 동료 1명에게 오늘 사례 1개 공유

Q&A 자주 나오는 질문 (강사 준비용)
  • "HWP 파일은요?" → 세 도구 모두 HWP 직접 지원이 불안정합니다. PDF로 저장해 올리거나, 한글에서 텍스트 복사. Gemini는 Docs로 변환 후 패널 사용.
  • "AI가 쓴 글이라는 걸 밝혀야 하나요?" → 기관 지침에 따릅니다. 원칙은 "초안 도구로 사용, 최종 책임은 작성자". 대외 문서는 사람이 검토·수정한 뒤 발송.
  • "내부망에서 접속이 안 돼요" → 기관 보안 정책입니다. 정보보안 부서에 업무용 허용 여부와 내부 구축형 AI 유무를 문의.
  • "결과가 매번 달라요" → 정상입니다. 형식·제약을 지침(에이전트)에 고정하면 편차가 줄어듭니다.
  • "어디까지 믿어도 되나요?" → 구조·문장·형식 변환은 높게, 사실·수치·조항은 낮게. 후자는 항상 원문 대조.
