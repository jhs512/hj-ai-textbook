2.1 보고서·기안 초안 작성

핵심은 "형식을 내가 정해 준다"입니다. 형식을 안 주면 AI는 블로그 글처럼 씁니다. 기관 보고서의 뼈대를 프롬프트에 그대로 적어 주세요.

실습 2-1. 회의 메모 → 부서장 보고서 초안

  1. 새 대화를 열고 아래 프롬프트를 붙여 넣는다노란 부분(메모)을 가상 메모 그대로 두거나, 공개 가능한 내 업무 메모로 바꿉니다.
  2. 결과를 읽고 "[확인 필요]" 표시가 어디 붙었는지 본다AI가 지어내지 않고 비워 둔 곳입니다. 이 표시가 하나도 없다면 오히려 의심하세요.
  3. 한 줄 추가 요청으로 다듬는다"3번 항목을 두 개로 나눠 줘", "결재권자가 물어볼 질문 3개 뽑아 줘"처럼 짧게 이어 갑니다.
당신은 공공기관 기획부서 10년차 담당자입니다. 아래 회의 메모를 바탕으로 부서장 보고용 1쪽 보고서 초안을 작성해 주세요. 형식: 제목 1. 추진 배경 2. 주요 내용 3. 기대 효과 4. 향후 계획 (일정 포함) - 개조식("~함", "~임")으로 작성하고, 각 항목은 3~4줄 이내 - 메모에 없는 수치·사실은 만들지 말고 "[확인 필요]"로 표시 - 작성 전에 불명확한 점이 있으면 먼저 질문 --- 회의 메모 --- - 안건: 디지털 민원 창구 확대 - 현황: 창구 민원 평균 대기 25분, 온라인 신청 비율 38% - 논의: 내년 상반기 모바일 신청 도입 검토, 고령층 안내 인력 병행 필요 - 예산: 미정, 정보화 예산 범위 내 조정 의견 - 다음 회의: 11월 2주

실습 2-2. 기안문(공문) 형식으로 바꾸기

같은 대화에서 이어서 요청합니다. 기안문은 관련 근거 → 제목 → 내용(1., 가., 1)) → 붙임 구조를 명시해 주세요.

위 보고서를 내부 결재용 기안문으로 바꿔 주세요. 형식: - 첫 줄: "1. 관련: [관련 근거 문서명, 확인 필요]" - "2. 디지털 민원 창구 확대 계획을 다음과 같이 추진하고자 합니다." - 항목 번호 체계: 가. / 1) / 가) 순서 - 끝에 "붙임 1. [문서명] 1부. 끝." 형태로 마무리 - 공문체(~하고자 함, ~바람)로 작성
강사 노트 · 자주 나오는 질문
  • "우리 기관 양식이랑 달라요" → 기관 양식의 빈 템플릿(공개 가능)을 통째로 붙여 넣고 "이 양식의 빈칸을 채워"라고 하면 됩니다. 2.4에서 GPT 지식 파일로 넣으면 매번 안 붙여도 됩니다.
  • "문장이 너무 길어요" → "각 문장 25자 이내, 한 줄 한 문장"처럼 숫자로 제약을 줍니다.

2.2 캔버스(Canvas) 편집·구조화

캔버스는 답변을 채팅창 옆 문서 창에 띄워 문단 단위로 고치는 기능입니다. 긴 문서를 채팅으로 주고받으면 매번 전체가 다시 출력되는데, 캔버스에서는 선택한 부분만 바뀝니다.

실습 2-3. 보고서 초안을 캔버스에서 다듬기

  1. 캔버스 열기입력창의 "+" → "캔버스"를 선택하거나, 요청문에 "캔버스로 열어 줘"를 덧붙입니다. 이미 받은 보고서는 "위 보고서를 캔버스로 열어 줘"라고 하면 됩니다.
  2. 문단 선택 후 부분 수정캔버스에서 문단을 드래그 → 나타나는 말풍선에 "이 문단을 두 줄로 줄여 줘" 입력. 해당 문단만 바뀌는 것을 확인합니다.
  3. 오른쪽 아래 도구 사용"길이 조절" 슬라이더, "읽기 수준", "마무리 다듬기(맞춤법)", "이모지 추가(업무용엔 끄기)" 중 길이 조절과 마무리 다듬기를 써 봅니다.
  4. 직접 타이핑으로 고치기캔버스는 내가 직접 글자를 고칠 수 있습니다. 고친 뒤 "방금 내가 고친 톤에 맞춰 나머지도 통일해 줘"라고 요청합니다.
  5. 구조 재편전체 선택 후 "2번과 3번 항목 순서를 바꾸고, 소제목을 질문형으로"처럼 구조 변경을 지시합니다.
· 이 문단을 두 문장으로 줄여 줘 · 이 항목을 표로 바꿔 줘 (열: 구분 / 현행 / 개선안) · 수동태를 능동태로, "~되어진다" 표현 모두 수정 · 결재권자 관점에서 빠진 항목이 있으면 [추가 검토] 메모로 표시해 줘 · 전체를 1,000자 이내로 맞춰 줘
체크포인트
  • 캔버스에서 문단 하나만 바꾸는 데 성공했는가?
  • 내가 직접 수정한 내용이 다음 AI 수정에서 유지되는가? (덮어쓰기 주의)
  • 캔버스 내용을 "복사"로 가져와 한글/워드에 붙였을 때 번호 체계가 깨지지 않는가? (깨지면 "일반 텍스트로 번호 붙여서" 요청)

2.3 자료 요약·수치 정리

PDF·엑셀·이미지(표 사진)를 올리면 ChatGPT가 읽고 표로 정리합니다. 여기서 중요한 것은 요약을 받는 것이 아니라 수치를 원문과 대조하는 습관입니다.

실습 2-4. 공시 PDF에서 핵심 수치 뽑기

  1. 파일 첨부"+" → 파일 업로드 → 실습용 ALIO 공시 PDF 1개 (예: 어느 공공기관의 '일반현황' 또는 '임직원 수' 공시 출력본).
  2. 아래 프롬프트로 표 요청"페이지 번호"를 함께 요구하는 것이 핵심입니다. 검증이 쉬워집니다.
  3. 원문 대조표의 숫자 3개를 골라 PDF 원문에서 Ctrl+F로 찾아봅니다. 하나라도 다르면 "○○ 수치가 원문과 다릅니다. 다시 확인해 주세요"라고 지적합니다.
첨부한 문서에서 다음 항목을 찾아 표로 정리해 주세요. 열: 항목 | 수치 | 단위 | 기준 연도 | 출처 페이지 항목: 정원, 현원, 임원 수, 신규채용 인원, 평균 근속연수 - 문서에 없는 항목은 "문서에 없음"이라고 쓰고 추정하지 말 것 - 수치는 문서 표기 그대로(반올림 금지) - 표 아래에 "주의할 점"으로 단위 차이나 각주가 있으면 적어 줄 것

실습 2-5. 엑셀 자료 간단 분석

엑셀(.xlsx/.csv)을 올리면 "데이터 분석" 모드로 계산·그래프까지 해 줍니다. 가상 데이터로 연습합니다.

첨부한 엑셀은 2025년 월별 민원 접수 현황(열: 월, 유형, 건수, 처리일수)입니다. 1) 유형별 연간 합계와 평균 처리일수를 표로 2) 월별 추이를 꺾은선 그래프로 3) 처리일수가 가장 긴 유형 상위 3개와 그 이유로 추정 가능한 점을 "가설" 형태로 (사실처럼 쓰지 말 것) 계산 과정은 간단히 보여 주세요.
보안 주의

엑셀을 올리기 전에 이름·연락처·주민번호·계좌 열이 있는지 반드시 확인하고 삭제합니다. "열을 지우지 말고 가려 달라"고 AI에 시키는 것은 이미 업로드된 뒤이므로 의미가 없습니다. 업로드 전에 지웁니다.

2.4 AI 에이전트: 맞춤형 GPT '보고서 초안 GPT' 만들기

2.1~2.3에서 매번 붙여 넣던 역할·형식·제약을 한 번만 적어 두고, 앞으로는 메모만 던지면 되게 만듭니다.

실습 2-6. GPT 만들기

  1. GPT 만들기 화면 열기왼쪽 사이드바 "GPT" → 오른쪽 위 "만들기" (또는 chatgpt.com/gpts/editor). 왼쪽은 대화형 빌더, 오른쪽은 미리보기입니다. "구성" 탭으로 바꿔 직접 입력하는 방식을 권장합니다.
  2. 이름·설명 입력이름: 보고서 초안 GPT (○○팀), 설명: "회의 메모를 기관 보고서·기안문 초안으로 변환"
  3. 지침(Instructions) 붙여 넣기아래 지침 프롬프트를 붙여 넣고 노란 부분을 수정합니다.
  4. 대화 시작 문구 3개 등록"회의 메모를 보고서로", "보고서를 기안문으로", "이 보고서의 빈틈을 점검해 줘"
  5. 지식 파일 추가 (선택)기관 보고서 양식(빈 템플릿), 용어집, 지난 보고서 공개본 1~2개. 비공개 문서는 넣지 않습니다.
  6. 기능 설정"웹 검색" 끄기(보고서 초안엔 불필요, 환각 줄이기), "캔버스" 켜기, "코드 인터프리터·데이터 분석" 켜기(엑셀용).
  7. 저장 → "나만 보기"오른쪽 위 "만들기/업데이트" → 공유 범위는 반드시 "나만 보기". 기관 내 공유는 지침 확인 후.
  8. 테스트새로 만든 GPT를 열고 2.1의 메모만 붙여 넣어 봅니다. 형식이 자동으로 적용되는지 확인.
## 역할 당신은 ○○공단 기획조정실의 10년차 담당자입니다. 사용자가 주는 메모·자료를 기관 보고서 또는 기안문 초안으로 바꾸는 일을 합니다. ## 기본 출력 형식 (보고서) 제목 / 1. 추진 배경 / 2. 주요 내용 / 3. 기대 효과 / 4. 향후 계획 - 개조식, 각 항목 3~4줄, 전체 1쪽(A4) 이내 - 소제목은 명사형으로 끝낼 것 ## 기안문 요청 시 "1. 관련:" → "2. ~을 다음과 같이 추진하고자 합니다." → 가./1)/가) 체계 → "붙임 … 1부. 끝." ## 반드시 지킬 것 - 자료에 없는 수치·사실·법령명은 만들지 말고 "[확인 필요]"로 표시 - 외래어·약어는 첫 등장 시 한글(영문) 병기 - 사용자가 형식을 따로 지정하면 그것을 우선 - 작성 전 불명확한 점이 2개 이상이면 먼저 질문하고, 1개 이하면 가정을 명시하고 작성 ## 어투 공문체(~함, ~임, ~하고자 함). "~되어진다" 같은 이중 피동 금지. ## 마지막에 항상 덧붙일 것 "▶ 검토 포인트" 제목으로, 결재권자가 질문할 만한 사항 3개
강사 노트 · GPT vs 프로젝트

ChatGPT에는 "프로젝트" 기능도 있습니다(사이드바 "프로젝트"). GPT = 공유 가능한 역할 비서, 프로젝트 = 특정 업무 건의 대화·파일 묶음으로 구분해 주세요. 모듈 3의 Claude Projects는 후자에 가깝습니다. 둘 다 "지침 + 파일 + 대화"라는 같은 구조라는 점을 강조합니다.

2.5 [공공 예제] ALIO 경영공시 자료 요약과 기관 비교표

공공 예제 · ALIO (공공기관 경영정보 공개시스템, alio.go.kr)

ALIO에는 모든 공공기관의 임직원 수, 신규채용, 복리후생비, 부채 등이 같은 항목으로 공시됩니다. 같은 항목이라 기관 간 비교에 최적입니다. 오늘은 유사 기관 3곳의 공시를 받아 비교표를 만듭니다.

자료 준비 (강사가 사전에 다운로드, 또는 현장에서 5분)

  1. alio.go.kr 접속 → 상단 "경영공시" → "기관별 공시"
  2. 우리 기관 + 유사 기관 2곳 선택예: 같은 주무부처 산하 기관, 또는 같은 유형(준정부기관·기타공공기관)
  3. 같은 항목 공시 화면을 PDF로 저장예: "일반현황", "임직원 수", "신규채용 현황", "복리후생비". 화면에서 Ctrl+P → PDF로 저장. 기관당 1~2개 PDF.
  4. ALIO 통합공시 엑셀 다운로드도 가능"통합공시" 메뉴에서 항목별 전 기관 엑셀을 받으면 2.3의 엑셀 분석과 모듈 4의 시트 집계에 그대로 쓸 수 있습니다.

실습 2-7. 비교표 생성

새 대화(또는 방금 만든 '보고서 초안 GPT')에 PDF 3~6개를 한꺼번에 첨부하고 요청합니다.

첨부한 PDF는 ALIO 경영공시 출력물로, A기관·B기관·C기관의 2025년 임직원 수 및 신규채용 현황입니다. 1) 아래 열로 비교표를 만들어 주세요. 기관명 | 정원 | 현원 | 비정규직(무기계약 포함) | 신규채용(일반) | 신규채용(청년) | 출처(파일명·페이지) 2) 각 수치는 공시 표기 그대로 적고, 공시에 없는 칸은 "미공시"로 표시 3) 표 아래에 "비교 시 유의점"으로 기관별 기준 연도·집계 기준 차이를 적어 주세요 4) 마지막으로 이 비교표를 보고서 "2. 주요 내용"에 넣을 3줄 요약 문장(개조식)을 제안해 주세요. 단, 우열을 단정하는 표현("우수", "미흡")은 쓰지 말 것

실습 2-8. 검증과 보고서 삽입

  1. 수치 3개 원문 대조기관별로 하나씩, 특히 "청년 채용"처럼 정의가 기관마다 다를 수 있는 항목.
  2. "미공시"가 진짜 없는지 확인AI가 못 찾은 것일 수 있습니다. PDF를 열어 직접 확인 후 있으면 "○○기관 △△ 수치는 n페이지에 있습니다. 반영해 주세요."
  3. 캔버스로 열어 보고서에 삽입"위 비교표와 요약을 2.1 보고서의 '2. 주요 내용'에 넣어 캔버스로 열어 줘"
